# Decision Inversion: *Learning from Supervision with Semantic and Episodic Memory*

## Scope and reading lens

This document inverts Hassell et al., “Learning from Supervision with Semantic and Episodic Memory: A Reflective Approach to Agent Adaptation,” CAIS ’26, DOI [`10.1145/3786335.3813154`](https://doi.org/10.1145/3786335.3813154). Close reading used the author-posted [`arXiv:2510.19897v3`](https://arxiv.org/abs/2510.19897) (4 May 2026), which identifies the same ACM paper and DOI.

The comparison target is **Kivi**, as specified in the attached position paper: a text-based personal work assistant whose semantic memory must be calibrated, must not retain third-party personal content, and must keep beliefs attributable, visible, revisable, and suppressible. Kivi distinguishes entities/preferences/episodes and stated/observed/hypothesised tiers; regular dictation receives lexical/entity memory only, while Hey Kivi receives permission-gated memory. References to “Kivi §…” below point to that attachment.

“Fit” is not a recommendation. It records whether the paper’s setting assumption transfers to Kivi and, when it does not, the direction of the mismatch.

## 2. Forced choices

These are the decisions whose alternatives would change the paper’s reported result or invalidate the inference drawn from it. “Load-bearing” refers to the paper, not to Kivi.

| Decision | Why it is load-bearing | Direct evidence in the paper |
|---|---|---|
| **F1 — D2/D4: Gold labels anchor every critique** | Without an authoritative answer, the method cannot distinguish a useful reflection from reinforced model bias; the semantic and episodic stores would no longer be “supervision-grounded.” | §2.1 says explicit answer restatement was introduced because critics persisted in incorrect prior understanding. |
| **F2 — D5: Preserve local, instance-specific reasoning** | Removing local rationale materially changes accuracy; global-only wins outright in only one of 21 ablation cells. The episodic mechanism’s advantage depends on more than storing an answer or a global rule. | Appendix E.3, Table 7. |
| **F3 — D7/D13: Store episodes and retrieve by similarity** | EP_CRIT and the hybrid depend on bringing a small, targeted set of full examples plus critiques into context; this is the best or near-best family across many settings. A different retrieval object or ranking signal could change which method wins. | §§3.2, 4.3; Tables 1–2. |
| **F4 — D8/D11: Use semantic memory mainly alongside episodic memory** | SEM_CRIT alone does not reliably beat EP_LABEL (`p=0.636`), while EP+SEM_CRIT averages +4.6 points over EP_LABEL. The paper’s claim for semantic memory is therefore load-bearing as a complement, not as a standalone replacement. | §4.3, Table 2. |
| **F5 — D14: Retrieval-set size** | Changing K produces up to an 8-point absolute difference within the same setup. K=5 is a consequential empirical choice even though K=10 is similar on average. | Appendix E.4, Table 8. |
| **F6 — D3: Choice of performance/critic model** | Gains vary sharply by model and domain. The paper’s interpretation depends on the model being able to use external reasoning; model scale alone is insufficient. | §§4.3, 4.5; Tables 1 and 4. |
| **F7 — D12: Put critique text directly into the inference prompt** | The claimed accuracy and 31.95% reasoning-token reduction arise because precomputed critique substitutes for inference-time reasoning. A design that stores critique but does not expose it to the model would not test the same mechanism. | §4.4; Table 3. |
| **F8 — D19/D24: Closed-set, forced-choice evaluation** | It makes accuracy cheap to compute and every timeout/abstention wrong. Allowing abstention, clarification, or open-ended outputs would change both scores and the meaning of errors. | §§4.1–4.2; Appendix B.2/C/E.5. |
| **F9 — D21: Monotonic episodic accumulation plus periodic full semantic regeneration** | The online-learning interpretation in Appendix E.2 assumes old examples stay valid and larger splits are strict supersets. Supersession, decay, or deletion would break that equivalence. | Appendix E.2, Table 6. |

## 3. Unexamined defaults

These are choices the paper uses as infrastructure or inherits from the surrounding literature without evaluating the choice as such.

| Default the paper inherits | Where it appears | Alternative this line of work rarely tests |
|---|---|---|
| **“Memory” means prompt material.** A memory matters by being inserted as text into the model context. | §§1, 3; Appendix C. | Memory as a typed, access-controlled belief service that answers bounded queries and may refuse disclosure without ever serializing all retrieved items into the generation prompt. |
| **A label is truth, not a claim with provenance.** | §2.1. | Labels as versioned assertions that can conflict, expire, be source-weighted, or be contested. |
| **Natural-language rationales are faithful enough to store.** The critic’s explanation is treated as useful reasoning, not as a post-hoc story requiring validation. | §2.1; Appendix C/D. | Store minimal evidence and testable transformations; regenerate explanations on demand while keeping the authoritative source separate. |
| **Semantic and episodic are the right top-level ontology.** | §3, citing cognitive-architecture literature. | Organize memory first by ownership, permission, temporal validity, or actionability; treat “episodic/semantic” as representations inside those policy classes. |
| **A single global semantic summary is a coherent object.** | §3.1. | Maintain competing/scoped semantic hypotheses with explicit applicability and contradiction links instead of forcing one consensus summary. |
| **Similarity is relevance.** | §3.2; Appendix B.1. | Retrieve for expected decision value, causal/relational match, or uncertainty reduction—even when surface semantics are dissimilar. |
| **Top-K is preferable to a calibrated empty result.** | §3.2. | Let retrieval return zero memories and make “nothing supports this” a first-class outcome. |
| **More context can be reconciled by the model.** Contradiction handling is delegated to attention/instruction following. | §3.3. | Resolve or surface conflicts before generation; prohibit silent reconciliation. |
| **Task boundaries are known and stationary.** Train/test are sampled from one dataset and old examples remain valid. | §§4.1–4.2; Appendix E.2. | Detect task drift and revise or retire memories when the target changes. |
| **Correctness errors are symmetric.** Every wrong multiple-choice answer counts equally. | §4.2. | Weight failures by action consequence, privacy harm, reversibility, or whether the system falsely claimed evidence. |
| **The user is an object to predict, not a participant controlling memory.** Preference history defines a hidden target; users never inspect or correct the inferred profile. | §4.1 and Appendix E.6. | Evaluate a user who sees, disputes, scopes, and withdraws memories, then measure whether the system honors those acts. |
| **Absence is a negative label, not a knowledge state.** | Preference task construction and forced-choice prompts in §4.1/Appendix C. | Distinguish “negative,” “unknown,” “not retained,” “withheld,” and “contradictory.” |
| **Memory ownership follows dataset partition.** | Per-user separation in §4.1. | Model multi-party consent and ownership at the claim/source level, particularly when one user supplies information about another. |

## 5. Evaluation gap

### What the paper measured

The paper measures:

- forced-choice **accuracy** across seven datasets and six models for zero-shot, label-only episodic retrieval, critique episodic memory, critique semantic memory, and their hybrid (§§4.1–4.3; Tables 1–2);
- **output/thinking-token use**, **token-limit timeouts**, and token **break-even** against EP_LABEL for reasoning models (§4.4; Tables 3 and 5; Appendix E.1/E.5);
- **suggestibility**, defined as the accuracy difference under truthful versus deliberately flipped-label critiques, and correlation with gains (§4.5; Table 4);
- sensitivity to **training-set size**, **critique components**, and **K** (Appendix E.2–E.4; Tables 6–8);
- per-user preference accuracy distributions (Appendix E.6).

These measurements support a narrow claim: on closed classification tasks with authoritative labels, putting label-grounded local/global critique into context often changes accuracy and can reduce inference-time reasoning tokens. They do not by themselves establish a safe, correct, user-legible long-term personal memory system.

### Decisions the metrics cannot distinguish

| Indistinguishable alternatives under the paper’s evaluation | Why they can score the same | Affected decisions |
|---|---|---|
| Retain a third party’s raw personal detail **vs** retain only a work-level residue. | Both can produce the same correct test label; there is no privacy or retention audit. | D7, D22, Kivi Q1–Q4. |
| A belief with source, timestamp, and status **vs** an unattributed prose instruction. | Accuracy sees only whether the final choice is correct. | D5, D8–D9, D18. |
| Retrieve a sensitive memory and silently use it **vs** retrieve it but withhold it under a permission policy. | There is no permission setting, disclosure state, or user-facing trace. | D17–D18. |
| Correctly abstain because evidence is absent **vs** confidently guess the benchmark label. | Abstention is necessarily marked wrong, so the metric favors guessing even when real-world evidence is absent. | D15, D19. |
| Supersede a stale preference **vs** keep both old and new statements and happen to choose the current answer. | Test sets do not contain temporal belief histories or inspect stored state. | D16, D21–D22. |
| Forget a memory and block re-derivation **vs** delete it temporarily and let it regrow. | No deletion/correction/reprocessing cycle is tested. | D20–D22. |
| Store an observation as tentative **vs** silently promote it to a rule. | Both may predict held-out preferences equally well; epistemic overreach is unscored. | D5, D8, D20. |
| Use five semantically similar examples **vs** a smaller causally or relationally relevant set. | Aggregate accuracy may match; evaluation does not measure retrieval precision, evidence sufficiency, or why an item was selected. | D13–D15. |
| Concatenate contradictory memories and let the model choose **vs** resolve conflicts explicitly before generation. | If both yield the same final label on non-conflicting test data, accuracy cannot tell them apart. | D12, D16. |
| Show a correct answer with no explanation **vs** show a correct answer plus accurate provenance and withholding trace. | User comprehension, trust calibration, and correction success are not measured. | D18, D24. |
| Same-model critic **vs** independent or human critic with equal benchmark accuracy. | The evaluation does not separately validate critique factuality, faithfulness, or harmful inference rate. | D3–D5. |
| Globally summarize all critiques **vs** scope memories by project/entity/time when test questions never cross scopes. | The benchmark gives a clean dataset/user partition, so leakage across real-world scopes cannot appear. | D8–D10, D23. |
| A model that obeys true memory because it is grounded **vs** a model that obeys any authoritative-looking text. | Suggestibility deliberately detects receptivity but not whether the model verified provenance; high scores coexist with misinformation vulnerability. | D4, D16, D20. |
| Low average token use with poor tail latency **vs** stable latency at the same mean. | Mean output tokens and timeout percentage do not expose full latency distributions or interactive responsiveness. | D14, D24. |
| A memory system that users can successfully correct **vs** one whose editable UI does not change downstream behavior. | No user study or end-to-end correction test exists. | D18, D20–D22. |

### Where the paper does provide comparative evidence

To avoid treating every paper choice as mere precedent, five comparisons genuinely discriminate among alternatives in its setting:

1. **Critique vs labels alone:** EP_CRIT and EP+SEM_CRIT significantly outperform EP_LABEL in aggregate (§4.3, Table 2).
2. **Semantic alone vs episodic/hybrid:** SEM_CRIT alone is substantially weaker; its evidence is mainly as a complement (§4.3).
3. **Local vs global critique content:** local reasoning is usually load-bearing, while global reasoning can add complementary value (Appendix E.3).
4. **Fixed K values:** K changes accuracy materially, with K=5 and K=10 similar on average in the tested GPT-4o-mini setup (Appendix E.4).
5. **Model receptivity and computation:** benefit varies by model/task, while critique context often reduces reasoning tokens (§§4.4–4.5).

None of these comparisons distinguishes Kivi’s central product decisions about retention boundaries, epistemic tiering, permission-gated disclosure, provenance UX, correction, suppression, decay, or abstention. For those decisions, this paper is precedent about in-context adaptation—not evidence that one Kivi design answer is better than another.
